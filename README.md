# Hotel Chul Mutton Baner - Sagar Takawale Group of Hotels

Auto-generated website for Hotel Chul Mutton Baner - Sagar Takawale Group of Hotels — Indian restaurant, 1, Hotel Chul Mutton Baner - Sagar Takawale Group of Hotels, Hotel Chul Mutton Survey no 119/5/11 and 120, 6, Balewadi High St, near My World Society, Baner, Pune, Maharashtra 411045.

## Tech Stack

- **backend**: Spring Boot 3 (Java 17) + Spring Data JPA
- **frontend**: React 19 + TypeScript on Vite, react-router-dom, Tailwind CSS
- **database**: PostgreSQL

## Features

- Integrated Online Ordering System (for delivery & pickup)
- Real-time Table Reservation System
- High-quality, professional food photography and videography
- Mobile-first, responsive design
- Multi-location management capability
- Prominent display of reopening status and date
- Schema markup for Restaurant, Menu, and Reviews to enhance SEO
- Integration with Google Maps for directions

## Running Locally

```bash
docker-compose up --build
```

The app will be available at http://localhost:8080

## Development

**Backend:**
```bash
cd backend && mvn spring-boot:run
```

**Frontend:**
```bash
cd frontend && npm install && npm run dev
```
