## Tech Stack

- **backend**: Node.js with Express.js (for real-time order/booking management)
- **hosting**: Vercel or AWS Amplify (for scalability and reliability)
- **database**: PostgreSQL (for structured data like orders, users, and reservations)
- **frontend**: Next.js or Gatsby (for performance and SEO)

## Features

- Integrated Online Ordering System (for delivery & pickup)
- Real-time Table Reservation System
- High-quality, professional food photography and videography
- Mobile-first, responsive design
- Multi-location management capability
- Prominent display of reopening status and date
- Schema markup for Restaurant, Menu, and Reviews to enhance SEO
- Integration with Google Maps for directions

## Running Locally

```bash
docker-compose up --build
```

The app will be available at http://localhost:8080

## Development

**Backend:**
```bash
cd backend && mvn spring-boot:run
```

**Frontend:**
```bash
cd frontend && npm install && npm run dev
```
